# Genomic results

A dataset containing information on Genome size and TE content for 808
taxids

## Usage

``` r
data(gen_res)
```

## Format

A data frame with 808 rows and 3 variables:

- taxid:

  NCBI taxid

- Genome_size:

  the Genome size in pb

- TEcontent_bp:

  the transposable element content in pb
