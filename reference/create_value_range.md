# Compute a new scale for a value

Compute a new scale for a value

## Usage

``` r
create_value_range(value, df, df2, min, max)
```

## Arguments

- value:

  A vector of values.

- df:

  The full dataframe.

- df2:

  The dataframe containing visibles taxa.

- min:

  The new minimum of the range.

- max:

  The new maximum of the range.

## Value

A vector of values.
